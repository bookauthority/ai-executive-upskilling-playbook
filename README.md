# AI at Scale: The Executive Playbook for Autonomous Upskilling and Reskilling

**Companion code and practical exercises for _AI at Scale: The Executive Playbook for Autonomous Upskilling and Reskilling_.**

**Book author:** Victor Thorne

## About the book

This book provides senior executives and C-suite leaders with actionable strategies, frameworks, and real-world case studies for leading large-scale, AI-driven autonomous upskilling and reskilling initiatives. It focuses on the intersection of organizational change management, talent strategy, and technology adoption, enabling leaders to navigate the complexities of workforce transformation in the age of artificial intelligence. Readers will gain insights into designing scalable programs, aligning AI-enabled learning with business objectives, and overcoming common barriers to adoption—all tailored to the unique needs and responsibilities of executive leadership.

## Who this is for

Senior executives and C-suite leaders responsible for organizational talent strategy and digital transformation.

## What you will find here

This repository accompanies the book with chapter-specific implementation projects, examples, and reproducible exercises. Each implementation folder has its own README with the setup and execution instructions relevant to that chapter.

## Getting started

1. Read the chapter you want to explore in the book.
2. Open the corresponding `chapter-XX/` folder above, where an implementation is available.
3. Follow that folder’s `README.md` for prerequisites, setup, configuration, and commands.
4. Run the chapter’s examples and compare the results with the discussion in the book.

Different chapters may have different dependencies and environment requirements; use the instructions in each chapter folder rather than assuming one setup works for all projects.
